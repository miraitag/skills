## useFieldArray — Dynamic Arrays in RHF Forms

**Impact: MEDIUM**

> **Scope:** repeatable field groups inside RHF. Stable keys in general →
> `lists-stable-keys`; runtime-described fields → `api-dynamic-schema-builder`.

Using `useState` for field arrays creates a parallel state outside of RHF — the
values don't appear in `handleSubmit`. `useFieldArray` integrates them directly.
`key={field.id}` (not the index) is mandatory so React reconciles correctly.

**Incorrect (useState for the array — outside of RHF):**

```tsx
// ❌ Array in useState: does not appear in handleSubmit
const [items, setItems] = useState(['']);

const onSubmit = (data: FormValues) => {
  console.log(data); // { title: "..." } — no items
  console.log(items); // Parallel state out of sync
};

// ❌ key={i} with index: React unmounts components on reorder
{
  items.map((item, i) => <View key={i}>...</View>);
}
```

**Correct (useFieldArray + key={field.id}):**

```tsx
const { control, handleSubmit } = useForm<OrderValues>({
  resolver: yupResolver(orderSchema),
  defaultValues: { items: [{ name: strings.common.empty }], title: strings.common.empty },
});

// ✅ useFieldArray: integrated into RHF, values in handleSubmit automatically
const { fields, append, remove } = useFieldArray({ control, name: 'items' });

// ✅ data.items contains all the array values; the view-model owns the side effect
const onSubmit = (data: OrderValues) => submitOrder(data);

{
  fields.map((field, index) => (
    // ✅ key={field.id}: stable ID generated by RHF — not the index
    <View key={field.id} style={styles.row}>
      <Controller
        control={control}
        name={`items.${index}.name`} // ✅ Dot notation for nested fields
        render={({ field: { onChange, onBlur, value } }) => (
          <TextInput value={value} onChangeText={onChange} onBlur={onBlur} />
        )}
      />
      {fields.length > 1 && (
        // ✅ Removes by index
        <Pressable onPress={() => remove(index)}>
          <Text>{strings.order.removeItem}</Text>
        </Pressable>
      )}
    </View>
  ));
}

{
  /* ✅ append with the correct initial object */
}
<Pressable onPress={() => append({ name: strings.common.empty })}>
  <Text>{strings.order.addItem}</Text>
</Pressable>;
```

> **Not the same as a runtime-built form:** `useFieldArray` repeats **one** fixed
> shape N times. When each field is different and comes from data (its id, label,
> and rules), use the `api-dynamic-schema-builder` rule instead.

Reference: [useFieldArray — React Hook Form](https://react-hook-form.com/docs/usefieldarray)

**In this repo:** React Hook Form **is** used, but the current password-reset
form has only fixed fields (`password`, `confirmPassword`), so `useFieldArray`
is not needed yet. Apply this rule when a screen adds a dynamic, repeatable
group of fields (e.g. a list of beneficiaries): integrate it into the same
`useForm<FormFields>` state with `useFieldArray` and `key={field.id}` instead
of a parallel `useState`, so the values flow through
`handleSubmit(viewModel.onSubmit)`.
